# Querida, mi niña ❤️

Web-regalo de cumpleaños para Zaira, hecha con HTML, CSS y JavaScript puro. Lista para publicar en GitHub Pages.

## Personalización antes de publicar

1. Añade vuestras fotografías:
   - `assets/photos/pareja/foto-1.jpg`
   - `assets/photos/pareja/foto-2.jpg`
   - `assets/photos/pareja/foto-3.jpg`
2. Añade una foto de Deizy:
   - `assets/photos/deizy/deizy-1.jpg`
3. Añade el archivo de audio que tengas derecho a utilizar:
   - `assets/music/nuestra-cancion.mp3`

La página muestra marcadores visuales si todavía no has añadido las fotos. El reproductor necesita el MP3 local; el nombre de la canción no descarga ni incluye el audio automáticamente.

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `querida-zaira`.
2. Sube **el contenido** de esta carpeta (index.html, css, js, assets y README.md) a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique la web. El enlace aparecerá en esa misma sección.

## Notas

- No necesita Node, npm ni compilación.
- Está diseñada primero para móvil.
- La música no empieza automáticamente: la persona debe pulsar reproducir, porque los navegadores suelen bloquear el autoplay.
- Para cambiar textos, edita `index.html`.
- Para cambiar colores y estilos, edita `css/style.css`.
